## 🦇 About Me

Halo! Saya **M. Bias Tegar Islami**, siswa SMK TI Dwiguna jurusan Pemrograman Perangkat Lunak dan Gim (PPLG). Saya adalah seorang **Creative Front-End Web Developer** dan **UI Designer** yang sangat menyukai dunia pembuatan website interaktif dan desain visual yang bersih (*clean design*).

- ⚔️ **Fokus Saat Ini:** Mengembangkan website interaktif yang estetik, rapi, dan fungsional.
- 🌱 **Keahlian Visual:** Mendesain UI/UX dengan Figma dan mengolah elemen desain secara maksimal menggunakan Canva.
- 🎯 **Filosofi:** *"What is a heart?"* — Layaknya pencarian makna sebuah hati, saya memadukan logika absolut (kode) dan estetika murni (desain) untuk menciptakan website yang bernyawa dan berkarakter.
